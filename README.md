Scheme Advisor

Scheme Advisor is a web application that helps users discover government schemes based on their personal details and eligibility.

Features

- User registration and login
- Browse government schemes
- Search and filter schemes
- Check scheme eligibility
- View scheme details
- Category-based scheme suggestions
- Official scheme links
- Simple and user-friendly interface

Technologies Used

- HTML
- CSS
- JavaScript
- React
- Node.js
- Express.js
- Database

How It Works

1. User creates an account or logs in.
2. User provides the required details.
3. The system checks available government schemes.
4. Eligible schemes are displayed to the user.
5. Users can view complete scheme information and visit the official portal.

Getting Started

Install Dependencies

npm install

Run the Project

npm run dev

The application will then be available on the local development server.

Purpose

The main goal of Scheme Advisor is to make government scheme information easier to discover and understand, especially by helping users identify schemes that may match their eligibility.

Disclaimer

Scheme information should be verified through the respective official government portal before applying.
